# **App Name**: TestPrep Digital

## Core Features:

- Chapter Navigation: Navigate through the 22 chapters of the test bank using a sidebar navigation menu.
- MCQ Display: Display multiple-choice questions, with question statements and five answer choices, for a selected chapter.
- True/False Display: Display True/False questions for a selected chapter.
- Answer Submission: Allow users to select an answer for each question.
- Immediate Feedback Tool: Provide immediate feedback on submitted answers, indicating whether the answer is correct or incorrect; optionally, provide explanation and reasoning using the LLM.
- Performance Tracking: Track the user's performance by chapter, displaying their score for each chapter.
- Detailed Question Metadata: Display additional information associated with each question: difficulty level, reference, key concepts, and MSC.

## Style Guidelines:

- Primary color: Vibrant blue (#29ABE2) to evoke trust and knowledge, drawing inspiration from educational resources. 
- Background color: Light gray (#F0F4F7) for a clean and distraction-free testing environment.
- Accent color: Green (#90EE90) to highlight correct answers and positive feedback.
- Body font: 'PT Sans', a humanist sans-serif font, for readability and a modern feel.
- Headline font: 'Space Grotesk' for chapter titles and headings.
- Use simple, clear icons for navigation and feedback, such as checkmarks for correct answers and arrows for moving between questions.
- Organize each chapter's content into a scrollable layout, with questions grouped logically and clear visual separation between questions.
